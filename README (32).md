# ⚔️ Морской Бой 10×10 (PvP & PvE)

Автономная стильная веб-игра **«Морской Бой»**, разделенная на отдельные файлы (`index.html`, `style.css`, `script.js`).

## 🚀 Что нового:
- **Английские буквы в сетке:** Координаты полей сверху отмечены латинскими буквами (`A, B, C, D, E, F, G, H, I, J`) и цифрами (`1-10`) слева.
- **Обновленный состав флота:**
  - 1-палубный корабль удален.
  - Добавлен второй 2-палубный корабль.
  - **Итоговый флот (4 корабля):** 1x4-палубный, 1x3-палубный, 2x2-палубных.
- **Современный неоновый дизайн:** Улучшена градиентная рамка полей, неоновые эффекты свечения и плавные переходы.
- **Точная индикация:**
  - `💧 Капля воды` — строго при промахе (в любую свободную ячейку).
  - `🔥 Огонь` — ранение отдельной палубы.
  - `✕ Крестик` — полностью потопленный корабль.

## 📁 Структура файлов:
- `index.html` — Разметка интерфейса.
- `style.css` — Стили сетки, индикаторов, рамок и неоновых эффектов.
- `script.js` — Полная логика игры (PvE Бот + PvP PeerJS).
- `README.md` — Документация.

## 🛠️ Запуск проекта
Скачайте все файлы (`index.html`, `style.css`, `script.js`, `README.md`) в одну папку и запустите `index.html` в браузере.
